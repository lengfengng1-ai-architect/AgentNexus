# 移动端媒体生成卡片 + 思考框样式重设计（探索草稿）

> 本文档为 brainstorming 产出的设计探索草稿，**不是正式 API 契约**。正式变更需经 `/opsx:explore` 澄清后，由 `/opsx:propose` 形成。

## 背景与问题

用户对移动端聊天整体满意，但点名两块「有点丑」：

1. **图片生成卡片（InlineImageCard）/ 视频生成卡片（InlineVideoCard）**
   - 编辑态：灰底白卡的通用表单样式（label + textarea + chip 按钮 + 大蓝按钮），是桌面端压缩版，与移动端玻璃拟态聊天氛围割裂
   - 字号过小（9–11px label / 11px 输入）、边框/阴影语言与聊天气泡不一致
   - 完成态：图片/视频 + 一排小按钮，无视觉层次、无品牌感
2. **思考过程（reasoning）展示框**
   - 流式时 `TypingReasoning` 逐字追加，气泡高度随内容无界增长，整个消息列表被撑开、抖动
   - 与正常文本混在一个 `whitespace-pre-wrap` 容器里，无独立视觉身份

## 现状约束（不可破坏）

- 交互流程不变：prompt 可编辑、AI 优化、尺寸/比例选择、生成中进度、完成态全屏/复制/重新生成 — 纯样式重设计，不改数据流
- PC 端沿用现有样式；仅 `variant === 'mobile'` 分支重设计
- 移动端设计 token 已存在：`--accent #1677ff`、`--surface`、`--border`、`--r-*`、`--ff`，玻璃拟态（blur 24px + saturate 1.8）已在输入栏/胶囊/面板使用

## 设计方向

### A. 媒体生成卡片（编辑态 + 完成态）

- **卡片容器**：与聊天输入栏同款玻璃质感 — 半透明白底 + 1px 半透明白边 + 轻阴影 + `backdrop-filter: blur(24px) saturate(1.8)`，圆角 `var(--r-lg)`（16px），替代现在的 `#f7f8fa` 灰底 + `#d9dee7` 硬边框
- **结构层级**：
  - 顶部一行：意图图标（🖼/🎬）+ 标题（「生成图片」/「生成视频」）+ 右侧 AI 优化按钮（收敛为小型描边 icon 按钮）
  - 参考图（若有）：缩略图条保持，圆角加大
  - textarea：去掉边框改为卡片内嵌分区（上下 hairline 分隔），字号升到 13px
  - 尺寸/比例选择：chip 按钮保持，选中态用 accent 实底 + 白字（现在只是浅蓝描边，存在感弱）
  - 生成按钮：全宽、accent 实底、圆角 22px（与发送按钮一致的胶囊语言），加渐变或投影增强品牌感
- **完成态**：
  - 图片：去掉灰底容器，图片直接大圆角展示（填满气泡宽度），底部一行轻量文字按钮（全屏 / 复制链接 / 重新生成），用 muted 色 icon+文字，不再三个小方按钮
  - 视频：同样去掉灰底，视频圆角 + 参数信息收敛为一行 muted 小字（`720P · 16:9 · 5s`，用 · 分隔而非三个 span），操作按钮同图片
- **加载态**：图片生成中的旋转圈 → 与视频一致的「状态行 + 进度条」或骨架屏（shimmer 占位），比现在居中大转圈更轻
- **目标气质**：iOS / Apple 风格轻卡片 — 层次靠留白和 hairline，不靠边框堆叠

### B. 思考框（reasoning）

- **独立视觉身份**：从正文 `whitespace-pre-wrap` 中拆出，渲染为独立小卡：
  - 标题行：「💭 思考中…」（流式）→ 完成后可折叠为「已完成思考」
  - 内容区：**固定高度**（约 96–120px，4–5 行 13px 文本），`overflow-y: auto`，内部自动滚到底部跟随最新内容
  - 样式：muted 文字 + 极浅底色（`--accent-softer`）或左侧 2px accent 竖条引用样式
- **固定高度**：用固定 `height`（非 max-height）保证流式过程中气泡总高度稳定，不再撑开消息列表
- 完成后是否保留：默认折叠成一行「已完成思考 ▾」，点击展开看全文（避免历史记录里每条都占一块）

## 范围

- 改动文件（预估）：`InlineImageCard.tsx`、`InlineVideoCard.tsx`、`ChatBubble.tsx`（reasoning 分支）、`screen-chat.css`（新增样式块）
- PC 端样式不动；后端不动；测试以视觉回归为主

## 待澄清（进入 /opsx:explore 时确认）

1. 思考框完成后默认折叠为一行，还是直接消失只留正文？
2. 图片完成态是否需要保留「重新生成」入口（现在可回到编辑态）？
3. 视频参数信息（720P·16:9·5s）保留展示还是去掉？
4. 卡片玻璃质感是否会与气泡白底撞色——是否改为纯白卡 + 细边框 + 阴影的更保守方案？
