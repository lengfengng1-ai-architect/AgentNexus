设计理念
🎯 All in One
每个功能都是一个 AI Agent，用户只需用自然语言描述需求，系统自动调用相关 Agent 组合完成任务。
💬

对话即入口

产品调研、市场分析、方案生成，都从一条自然语言消息开始。无需学习复杂的菜单层级。

🧩

自由组合

17 个 Agent 像乐高积木一样可按需拼接。临时组合快速验证，也可走完整流水线出深度方案。

⚡

编排即流水线

预制 10 节点营销方案流水线，一键从需求到完整方案。每个节点是独立 Agent，可被复用或替换。

桌面端（PlanPage）

完整方案工作台：表单填写 + 流水线可视化 + 方案预览 + 行动卡片 + 海报/视频预览 + 图片放大 + 导出

移动端（MobileWorkbench）

五屏流程：聊天入口 → 简报表单 → 方案生成 → 行动建议 → 下发转达。手机框内嵌，统一维护。

📱 PhoneFrame 模拟真机 ⚡ 快捷按钮一键触发 🔍 卡片筛选：全部/海报/短视频/赛事/第三方 ✏️ 修改意见 → AI 优化提示词 → 重新生成
