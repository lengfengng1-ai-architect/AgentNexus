## ADDED Requirements

### Requirement: 输入框聚焦时显示沉浸式推荐态
当聊天会话为空且用户聚焦输入框时，系统 MUST 在聊天区域顶部显示沉浸式推荐态，包含问候语、推荐输入卡片和换一批入口。

#### Scenario: 空会话聚焦输入框显示推荐区
- **WHEN** 用户进入聊天屏且 `messages.length === 0`
- **WHEN** 用户点击输入框使其聚焦
- **THEN** 系统显示 "Hi, 老板" 问候语
- **THEN** 系统显示 4 个推荐输入卡片
- **THEN** 系统显示 "🔄 换一批" 入口

#### Scenario: 有历史消息时不显示推荐区
- **WHEN** 聊天区域已存在至少一条消息
- **WHEN** 用户点击输入框使其聚焦
- **THEN** 系统不显示顶部推荐区
- **THEN** 系统仅高亮输入框

### Requirement: 推荐输入区支持换一批
系统 MUST 允许用户通过 "换一批" 入口重新随机展示一组推荐输入卡片。

#### Scenario: 点击换一批刷新推荐
- **WHEN** 用户点击 "🔄 换一批"
- **THEN** 系统从推荐池中随机抽取 4 个未展示过的文案
- **THEN** 系统重新渲染推荐卡片
- **THEN** 当池耗尽时系统自动重置抽取状态

### Requirement: 输入框左侧提供 + 号按钮
系统 MUST 在输入框左侧提供 + 号按钮，用于展开/收起底部操作面板。

#### Scenario: 点击 + 号展开面板
- **WHEN** 用户点击 + 号按钮
- **THEN** 系统从底部滑出操作面板
- **THEN** + 号图标旋转 45° 变为关闭 ×

#### Scenario: 再次点击 + 号关闭面板
- **WHEN** 用户再次点击 + 号按钮
- **THEN** 系统收起操作面板
- **THEN** + 号图标恢复原始状态

#### Scenario: 点击面板外部关闭面板
- **WHEN** 操作面板处于展开状态
- **WHEN** 用户点击面板外部区域
- **THEN** 系统收起操作面板

### Requirement: 操作面板提供上传附件、创建图片、创建视频入口
系统 MUST 在操作面板中提供三个功能入口：上传附件、创建图片、创建视频，且点击后调用现有对应逻辑。

#### Scenario: 点击上传附件
- **WHEN** 用户点击 "上传附件"
- **THEN** 系统触发文件选择器
- **THEN** 用户选择文件后调用现有 `/upload` 逻辑

#### Scenario: 点击创建图片
- **WHEN** 用户点击 "创建图片"
- **THEN** 系统调用现有 `addVirtualMessage('text_to_image', ...)` 逻辑
- **THEN** 系统收起操作面板

#### Scenario: 点击创建视频
- **WHEN** 用户点击 "创建视频"
- **THEN** 系统调用现有 `addVirtualMessage('generate_video', ...)` 逻辑
- **THEN** 系统收起操作面板

### Requirement: 语音输入按钮移至输入框内部
系统 MUST 将语音输入按钮移至输入框内部右侧，并根据输入内容动态切换为发送按钮。

#### Scenario: 空输入时显示语音按钮
- **WHEN** 输入框内容为空
- **THEN** 输入框右侧显示麦克风图标按钮

#### Scenario: 有文字时显示发送按钮
- **WHEN** 用户在输入框中输入任意文字
- **THEN** 输入框右侧显示发送箭头按钮
- **THEN** 麦克风图标隐藏

#### Scenario: 点击语音按钮开始/停止语音识别
- **WHEN** 用户点击麦克风图标
- **THEN** 系统启动浏览器语音识别
- **THEN** 再次点击时停止识别
