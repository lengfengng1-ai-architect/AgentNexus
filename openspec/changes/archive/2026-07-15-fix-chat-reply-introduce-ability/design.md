## Context

`intent_recognition.md.j2` 中 chat 规则（第 73 行）：无 reply 指引。LLM 自由发挥为"你好！请问有什么可以帮助您的？"。

## Decisions

将 chat 规则改为：

```
10. chat → 以上都不匹配时，才是闲聊/打招呼。
    reply 应简短介绍自己的能力。例如：
    「你好！我是 AllyGo 营销方案助手。我可以帮您生成营销方案、进行市场分析、生成海报或宣传视频。
    请告诉我您的品牌、品类、城市、预算和周期等信息，我来为您定制方案。」
```

引导用户说出关键字段，降低冷启动门槛。

## Risks / Trade-offs

无。
