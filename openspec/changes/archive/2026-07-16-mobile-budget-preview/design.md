## 交互设计

### 饼图拖拽
- 鼠标/手指在饼图扇区上按下启动拖拽
- 拖拽时扇区向外弹起 6px，视觉深度反馈
- 鼠标跟随显示 tooltip（"达人合作 33%"）
- 其他扇区按比例自动平衡，确保总和为 100%
- 拖拽结束后提示文字淡出

### KPI 联动公式
- 曝光量 = 基准 × (0.2 + 0.6×平台投放/20% + 0.2×活动执行/30%)
- 点击量 = 基准 × (0.3 + 0.5×平台投放/20% + 0.2×内容制作/20%)
- 转化量 = 基准 × (0.2 + 0.5×内容制作/20% + 0.15×活动执行/30% + 0.15×运营资源/10%)
- 互动量 = 基准 × (0.3 + 0.5×达人合作/25% + 0.2×活动执行/30%)

### 里程碑预算分配
- 预热期 = 内容制作×0.6 + 达人合作×0.2 + 0.08
- 爆发期 = 活动执行×0.7 + 平台投放×0.6 + 达人合作×0.5 + 0.08
- 收尾期 = 运营资源×0.8 + 0.08
- 三段归一化后乘以总预算

## 数据流

```
后端 budget_kpi 输出
  → pausedSnapshot.upstream_outputs.budget_kpi
    → 弹窗显示 total_budget + period_months
    → 点击"预览预算" → 全屏页初始化
      → 用户拖拽调整 → 实时联动 KPI/里程碑
      → 点击 ‹ 返回
        → approveWithBudget(adjustments)
          → approvePlanRun(runId, { edited_input: { budget_kpi_adjusted } })
            → 后端继续流水线
```
